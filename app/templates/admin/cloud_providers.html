Connecteurs cloud — credentials OAuth

{% if is_sovereign %}
Mode souverain (air-gap) : les connecteurs OAuth (Google Drive / OneDrive / Dropbox / kDrive) sont désactivés car ils nécessitent un accès Internet vers les serveurs des providers. En air-gap, seuls S3-compatible (MinIO interne) et WebDAV (Nextcloud interne) sont disponibles.
Vos utilisateurs configurent leurs identifiants S3/WebDAV directement depuis /user/cloud — aucune configuration OAuth globale requise ici.
{% elif is_hybrid %}
Mode souverain-hybride : vos utilisateurs peuvent indexer Google Drive / OneDrive / Dropbox / kDrive uniquement si vous enregistrez vos propres apps OAuth chez chaque provider. Les credentials de myeline.io ne fonctionnent que pour le SaaS central.
Walkthrough complet : docs/deployment-sovereign-hybrid.md
{% endif %}

Pour activer un connecteur, créez l'app OAuth chez le provider, puis autorisez le redirect URI ci-dessous, et ajoutez le couple client_id / client_secret dans .env avant de redémarrer (podman-compose restart web).
